# Идеи для визуалов

Источник — общее направление премиальных визуальных клиентов и модов (Lunar, Feather, Badlion, моды-эффекты для Fabric, VFX в играх: Overwatch, Valorant, Genshin): что смотрится «дорого». Чужой код, текстуры и шейдеры не брались — всё своё, процедурное.

Общие принципы, которые повторяются у всех «дорогих» эффектов:
- **меньше, но мягче**: тонкие линии + широкий слабый ореол вместо толстых ярких полос;
- **цвет из одной палитры** на всё, белая «горячая» серединка, к краю — насыщенный тон;
- **движение с затуханием**: ease-out на появление, длинный мягкий хвост на исчезновение, никаких мгновенных вспышек;
- **реакция на событие** (удар, крит, прыжок) короткой волной и 5–10 искрами, а не облаком частиц.

## Бой
- **Маркер цели**: (1) тонкое кольцо у ног с мягким ореолом и медленным вращением штрихов; (2) «орбита» — 3 огонька с плавным шлейфом-лентой; (3) стеклянный ромб над головой, плавно качается, грань ловит свет; (4) «душа» — 2 призрачные ленты спиралью вокруг тела. Плавная смена цели (маркер «перетекает»), пульс при ударе.
- **Hit FX**: одна кольцевая волна по плоскости взгляда + 6–8 искр-штрихов (вытянутых по скорости) + лёгкий пульс маркера. Крит — та же волна ярче, звёздочка.
- **Kill FX**: силуэт растворяется снизу вверх частицами, из центра поднимается «душа» (лента) и уходит вверх, под ногами — расходящееся кольцо света. Кулдаун, чтобы не было спама.
- **Цвет урона**: цвет + сила + плавное затухание оттенка.
- **Прицел**: точка/кольцо/плюс; кольцо готовности удара заполняется по ванильному кулдауну; при попадании — короткий «пульс» масштаба.

## Игрок
- **Jump Circles**: двойное мягкое кольцо (ореол + тонкая кромка), второе с задержкой, лёгкое «свечение земли» в центре.
- **Trails**: лента по сплайну Catmull-Rom (по кадрам, не по тикам), сужается к хвосту; стили: лента света, звёздная пыль (лента + мерцающие точки без мигания), стеклянный шлейф (почти прозрачный с яркой кромкой). Отдельно — на элитрах.
- **China Hat**: градиент от прозрачного центра к краю, мягкая кромка, тонкий светлый обод, покачивание от движения головы.
- **Totem FX**: вместо ванильного «спама» — вспышка-кольцо вокруг тела, 2 кольца вверх, золотые искры с медленным падением.

## Мир
- **Block Overlay**: тонкая обводка с градиентом по высоте, едва заметная заливка, «перетекание» при смене блока, прогресс ломания — заполнение граней от центра.
- **Item Physics**: плавное падение и укладывание плашмя, лёгкое свечение редких предметов (по цвету редкости, без мигания).
- **Enchant Glint**: свой цвет блеска (перекраска текстуры блеска).

## HUD
- Плашки — стекло с размытым фоном, одинаковые радиусы; уведомления — «остров» сверху, который растягивается под текст и сжимается обратно.
- Target HUD — голова скина, полоса здоровья с «догоняющей» второй полосой (как в файтингах), броня.

## Свои идеи (делаю)
1. **Speed Lines** — тонкие светлые штрихи по краям экрана при быстром беге и на элитрах, плотность от скорости. Чувство скорости без размытия.
2. **Frost Breath** — лёгкий пар изо рта в холодных биомах и на высоте: маленькие мягкие облачка, тают за секунду.
3. **Cinematic** — режим кадра по клавише: киношные полосы сверху и снизу, без HUD, мягкая виньетка. Для скриншотов.
4. **Hurt Vignette** — мягкая цветная виньетка по краям экрана при уроне вместо резкого красного, сила от урона.
5. **Slot Pulse** — при смене слота предмет в руке на мгновение «вспыхивает» лёгким контуром (через ауру предмета).
