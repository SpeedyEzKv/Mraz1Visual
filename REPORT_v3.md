# Отчёт: обновление v3 (PvP, HUD, оптимизация, «Моды», дизайн)

Ветка `v2-multiversion`, по коммиту на этап. Все четыре версии Minecraft (1.21.11, 26.1.2, 26.2, 26.3) собираются из одного кода.
Скриншоты стенда 1.21.11 — `screenshots/v3/`.

## Этап 1 — PvP
Сделано (вкладка **PvP**, всё выключено по умолчанию, сверху плашка о риске бана):
- **Trajectories** — линия полёта жемчуга, снежков, яиц, зелий, опыта, стрел (по натяжению лука), арбалета, трезубца + точка падения.
- **No Interact** — с оружием не открываются сундуки/печи/двери (Shift — открыть).
- **Key Pearl** — бросок жемчуга по клавише из хотбара (одно нажатие — один бросок).
- **Panic Disconnect** — клавиша паники добавлена в бывший Auto Leave (выход при малом HP / рядом чужой — уже был).
- Перенесены во вкладку: Elytra Swap, No Friend Damage. Friends (колёсико мыши), Streamer Mode (скрытие ника), профили с экспортом в JSON — уже были.

**Не сделано сознательно:** Trigger Bot, Aim Assist, Crystal/Anchor/Double/Safe Anchor macro, Crystal Tweaks, Hover Totem/Potion, Fast XP,
Pearl Catch, Mace/Breach Swap, Auto Mace, Stun Slam, Shield Breaker, Spear Reach/Lunge, Wind Charge macro, Wind Jump, Cobweb/Plate Web,
Sword Place Obsidian, Anti Trap, Jump/Tap Reset, No Slow, Speed Bridge, пресеты «Меч/Копьё».
Это автоприцел, автоудар и боевые макросы против живых игроков — нечестное преимущество на серверах, где это запрещено (FunTime в их числе).
Остальной клиент так и устроен (FEATURES.md: «нет авто-действий в бою»), эту границу я сохранил.

## Этап 2 — функции как в Lunar
- **Редактор HUD**: перетаскивание, колесо — масштаб, примагничивание к краям и центру, сетка, Shift — без привязки, ПКМ — сброс.
- HUD-моды: FPS, CPS, Coordinates (+направление, биом, Незер), Ping, Server Address, Clock, Memory, Combo, Reach, Pack, Day, Saturation, Item Counter;
  Keystrokes, Armor, Potions получили режим «Свободно (редактор HUD)» — старые настройки угла сохранены.
- Zoom колесом мыши, Free Look выключается на серверах из `freelook-blocked.txt` (по умолчанию hypixel.net), Toggle Sneak,
  Particle Multiplier (больше искр при ударе, меньше прочих частиц), погода в Ambience (ясно/дождь/гроза), Kill Message → «Auto GG».
- Уже были и не дублировались: Toggle Sprint (Auto Sprint), Crosshair, Block Outline, Hit Color, Motion Blur, Fullbright, Time Changer,
  1.7/Swing Animations, Item Physics, Name Tags, Scoreboard, Chat (история, без очистки, время), Screenshots, Waypoints, Phrase Wheel (Auto Text).
- **Не сделано:** копирование сообщения из чата и размер скорборда — нужен разбор строк чата/скорборда, разный в каждой версии; оставил на потом.

## Этап 3 — оптимизация
- Лаунчер: профиль **«Оптимизация»** — Sodium, Lithium, FerriteCore, ImmediatelyFast, Entity Culling, ModernFix, Dynamic FPS, More Culling:
  свежая сборка с Modrinth под выбранную версию (через API, в jar не вшиваются), обязательные зависимости (Cloth Config для More Culling), без дублей.
  Лицензии проверены по Modrinth: Polyform Shield (Sodium), LGPL-3.0, MIT, GPL-3.0, tr7zw Protective (Entity Culling — нельзя перезаливать, ставить с Modrinth можно).
  ModernFix для Fabric под эти версии не выпускается — пропускается сам.
- JVM: G1 под клиент (паузы 37 мс, молодое поколение 20%, регионы 16 МБ, дедупликация строк) или ZGC (Java 21+); флаги проверены на Java 21 и 26 —
  `-XX:+ZGenerational` на Java 24+ роняет запуск, поэтому ставится только для 21. Ползунок RAM и выбор Java под версию уже были.
- Клиент: лимит FPS, когда окно не в фокусе (по умолчанию 30), бенчмарк 30 с в Frame Stats (средний FPS, 1% и 0.1% low),
  HUD без аллокаций в кадре (кэш строк и ширин), Potions считается раз в тик, частицы режутся до создания.
- **Не сделано:** «настоящий» кэш HUD в текстуру (рисовать раз в N кадров) — элементы и так дешёвые; совместимость модов оптимизации с нашими миксинами
  проверена только по зависимостям, не запуском каждого мода.

## Этап 4 — «Моды»
- Лаунчер: кнопка **«Моды»** открывает `mods` выбранной версии (создаёт, если нет); «список ›» — окно: вкл/выкл (`.jar.disabled`),
  удаление (с подтверждением), перетаскивание .jar, предупреждение о версии Minecraft/Fabric из `fabric.mod.json`. Моды, которые ставит лаунчер, заблокированы.
- Клиент: вкладка **Mods** со списком загруженных модов и кнопкой «Открыть папку модов».

## Этап 5 — дизайн
- **Боковая панель вкладок** с иконками (по умолчанию; «сверху» — в настройках клиента), стеклянная «капля», анимации — как в остальном меню.
- Тёмная/светлая тема, акцентный цвет, поиск, карточки, анимации — уже были (iOS 26 / Liquid Glass).
- Язык: `Lang` + `lang/ru_ru.json` / `en_us.json`, выбор языка в настройках. **Частично:** через файл идут только новые строки;
  перенос сотен старых русских строк меню в файл — отдельная работа.

CI: в `build.yml` добавлена сборка лаунчера (.exe артефактом) на ветках и PR; .exe локально не собирал — только `cargo check`/`cargo test`.
