# План ночи `visual-polish` (рабочий файл — по нему продолжает страховочная задача)

Правила: только визуал на моей стороне, без информации сквозь стены; небо внешне не трогать; импорт моделей не ломать;
в `main` не пушить, без force-push; после каждой функции `./gradlew build` (папка `mod`); маленькие коммиты, пуш после блока.
Ветка `visual-polish` = `main` + влитый `feature/model-import` (PR #3 ещё открыт — чтобы не было конфликтов).

Отметка: [x] — сделано и закоммичено.

## 1. База эффектов
- [x] `VisualFx` («Эффекты: общее», всегда включён): качество, яркость, «Без вспышек», один пресет на все визуалы
- [x] `Palette`: пресет «Акцент клиента»; «Радуга» в старых модулях — мягкий пастельный перелив
- [x] `Ease`: expo/back/elastic/smooth/approach
- [x] `FxParticles` v2: точка, искра по скорости, звёздочка, кольцо; проход свечения; турбулентность; ease-out; лимит по качеству; очистка при смене мира
- [x] `Ribbon`: лента по кадрам, Catmull-Rom, затухание по длине и времени, виды «к камере / стенка / плоская»
- [x] `FxDraw`: мягкое кольцо, ореол, штрихи, стеклянный ромб
- [x] Bloom: вместо общего пост-прохода — ореолы в аддитивном проходе (решение в отчёте); квады свечения в мире двусторонние
