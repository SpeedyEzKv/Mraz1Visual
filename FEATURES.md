# Возможности Mraz1Visual

Только клиент и визуал: ничего не отправляется на сервер без действия игрока, нет ESP сквозь стены, автоприцела, автоудара и боевых макросов.

## Меню (v2)
- Окно по центру поверх размытого мира, стиль Liquid Glass; тёмная и светлая тема, анимации открытия и переходов.
- Вкладки — **боковая панель слева** (по умолчанию) или полоса сверху (настройки клиента → «Вкладки»): Игрок, PvP, HUD, Визуалы, Шейдеры, FPS и разное, Staff, Косметика, Маркет, Моды, Форум, Музыка, Конфиги — стеклянная «капля» перетекает к выбранной.
- Язык интерфейса — файлы `assets/mraz1visual/lang/*.json` (русский; английский пока частично).

## PvP (всё выключено по умолчанию, сверху — предупреждение о бане)
- **Trajectories** — линия полёта жемчуга, снежков, яиц, зелий, опыта, стрел (по натяжению лука), арбалета и трезубца с точкой падения; ванильная физика, без аллокаций.
- **No Interact** — с оружием в руке ПКМ не открывает сундуки/печи/двери (Shift — открыть всё равно).
- **Key Pearl** — бросок эндер-жемчуга по клавише из любого слота хотбара (одно нажатие — один бросок).
- **Panic Disconnect** — выход по клавише, при малом HP или когда рядом чужой игрок (бывший Auto Leave).
- **Elytra Swap**, **No Friend Damage**; друзья — колёсико мыши по игроку (Friends).

## HUD
- **Редактор HUD** (вкладка HUD → HUD Editor или своя клавиша): элементы тянутся мышью, колесо — масштаб, примагничивание к краям и центру, сетка 8 px, Shift — без привязки, ПКМ — сброс. Место хранится долей экрана — элемент остаётся у своего края при смене размера окна.
- Элементы: FPS, CPS (ЛКМ | ПКМ), Keystrokes, Armor, Potions, Coordinates (+ направление, биом, координаты Незера), Ping, Server Address, Clock, Memory, Combo, Reach, Pack, Day, Saturation, Item Counter (тотемы, кристаллы, жемчуг, стрелы, яблоки). У каждого — фон, тень, цвета, масштаб.
- Строки пересобираются только при изменении данных; в кадре нет `String.format` и новых списков.
- Справа: поиск по модулям и настройкам (печатать можно сразу), настройки клиента, друзья, уведомления, аватар.
- Слева — список модулей с секциями и мини-переключателями; стрелки ↑↓ — соседний модуль, Enter/Пробел — вкл/выкл, Tab — следующая вкладка.
- Справа — баннер с **живым превью** модуля: ночная сцена (кирпичная стена, фонари, луна, манекены игрока и цели), сценарии боя, движения, косметики, HUD и атмосферы; цвет, стиль и размер — из настроек модуля; параллакс от мыши; «● ПРЕДПРОСМОТР», клавиша и главный переключатель.
- Под баннером — карточки настроек по группам: сегменты, ползунки, цвета, клавиши.
- «Классическое меню» — в настройках клиента (Вид меню).

## Шейдеры
- **Mraz1 PostFX** (без Iris): свечение Dual Kawase, ACES / AgX, 9 пресетов (iOS Day, Golden Hour, Midnight Glass, Cinematic, Frost, Neon Night, Aurora, Film 35, Нейтральный), SSAO-lite, лучи солнца, глубина резкости, атмосферный туман, виньетка, зерно, хроматическая аберрация, эффект под водой, качество Низкое/Среднее/Высокое. Небо по умолчанию не трогается. С шейдерпаком Iris выключается сам.
- **Mraz1 Shaders** для Iris (свой код): тени с PCF, вода с френелем, рябью, бликами и отражениями (SSR), тёплый свет от блоков, качание листвы и травы, блики LabPBR, профили. Ставится в `shaderpacks` автоматически при наличии Iris.
- Motion Blur — отдельный модуль.

## Гардероб (Cosmetics)
- Категории со счётчиками, фильтр по цвету, сетка из 34 вещей (крылья, плащи, головные уборы, ауры, питомцы).
- 3D-витрина с твоей моделью: поворот мышью и кнопками, авто-поворот.
- Наведение — примерка (после ухода мыши всё как было), клик — надеть/снять.
- Встроенный каталог моделей оружия и косметики (Blades of Majestica, Weapons Pack, Fantasy Sword, свой набор).

## Маркет
- Modrinth: моды, ресурспаки, шейдеры; сортировки, «только текущая версия», фильтр разрешения; установка с проверкой sha1 и удаление своего.
- Подборка Mraz1: Sodium, Iris, ImmediatelyFast, Entity Culling, Lithium, Mod Menu, Simple Voice Chat, ReplayMod, миникарта.

## Форум
- GitHub Discussions репозитория; вход через GitHub Device Flow (код на github.com/login/device), токен хранится только локально.

## Staff и быстрые действия
- **Staff Wheel** — колесо команд модератора; показываются только команды, разрешённые сервером (по дереву команд).
- **Phrase Wheel** — колесо фраз в обычный чат. Списки — `config/mraz1visual/*.txt`.

## Музыка
- Встроенный плеер (mp3, ogg, flac, wav), библиотека, плейлисты, эквалайзер, кроссфейд; тексты песен синхронно (LRCLIB и свои .lrc); «Сейчас играет» и статус Discord.

## Лаунчер
- **Моды**: кнопка открывает папку `mods` выбранной версии; «список ›» — моды с переключателем (`.jar.disabled`), удалением, установкой перетаскиванием .jar и предупреждением, если `fabric.mod.json` просит другую версию Minecraft/Fabric.
- **Оптимизация**: Sodium, Lithium, FerriteCore, ImmediatelyFast, Entity Culling, Dynamic FPS, More Culling (+ Cloth Config) — свежие сборки с Modrinth под выбранную версию; ModernFix ставится, когда появится сборка для Fabric.
- Память — ползунок; сборщик мусора G1 (настроен под клиент) или ZGC (Java 21+).
- Выбор версии Minecraft с бейджами «Рекомендуется / Новая / Бета».
- Автоустановка Java (21 или 25), Minecraft, Fabric Loader и Fabric API; Sodium и Iris по галочке; проверка sha256 своего jar.
- Профиль на версию (свои моды и миры), общий конфиг клиента; маркет в профиле выбранной версии.
- «Что нового» — новые обновления сверху.
