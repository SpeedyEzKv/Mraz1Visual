# Umbra — итерация 1.5 (фундамент + меню игры)

Fabric 1.21.11, только клиент. Визуалов пока нет — только каркас.

## Сборка
```
gradlew build            (Windows: gradlew.bat build)
```
jar: `build/libs/umbra-0.1.0.jar` → в `mods` вместе с Fabric API.

Запуск dev-клиента с демо-модулем: `gradlew runClient`.

Нужна Java 21. Первая сборка качает Minecraft и Fabric (~5 минут).

## Проверка «готово»
1. В мире жмёшь Right Shift → открывается окно.
2. Вкладки переключаются; пустые показывают заглушку.
3. «Настройки»: тумблер, слайдер, сегменты, цвет, бинд работают.
4. В dev-клиенте Visuals → Demo: все компоненты, включая выпадающий список.
5. Перезапуск → всё на месте (`config/umbra.json`).
6. Испорти `umbra.json` → игра стартует, значения по умолчанию, рядом `umbra.json.broken`.

## Управление в окне
- Печатаешь — сразу поиск по модулям. Enter открывает первый найденный.
- ПКМ по модулю в списке — вкл/выкл.
- ПКМ по строке настройки — сброс к умолчанию.
- Esc или клавиша меню — закрыть. Клик мимо окна — закрыть.

## Как добавить визуал
1. Класс в `dev.umbra.module`, наследник `Module`:
```java
public final class HitEffects extends Module {
    final SliderSetting size = add(new SliderSetting("size", "Размер", 1, 0.5, 2, 0.1, "×"));
    public HitEffects() { super("hit_effects", "Hit Effects", "Частицы при ударе.", Category.VISUALS); }
}
```
2. Одна строка в `core/Modules.java`: `m.register(new HitEffects());`

## Где править, если сборка ругается на API Minecraft
Здесь сборка не запускалась (нет доступа к репозиториям Fabric/Mojang). Код проверен компиляцией на заглушках.
Всё, что зависит от API игры, собрано в трёх файлах:
- `input/Keys.java` — опрос клавиш;
- `ui/Draw.java` — рисование;
- `ui/UmbraScreen.java` — события мыши и клавиатуры.

## Меню игры (итерация 1.5)
- Главное меню: затмение, пункты слева (Одиночная / Сетевая / Umbra / Настройки / Выход), ник справа сверху.
- Серверы: Серверы / Добавить / По адресу / Назад. Двойной клик или Enter — зайти, ПКМ или Delete дважды — удалить, ↑↓ — выбор, Ctrl+V в полях.
- Выключается в Umbra → Настройки → «Меню игры» (вернётся ванильное).
- Шрифты Manrope и Unbounded (OFL), фон нарисован с нуля — своё, не чужое.
- Новые файлы, зависящие от API игры: `mixin/MinecraftMixin.java`, `ui/Fonts.java`, `ui/menu/ServerPing.java`, `ui/menu/MenuBase.java` (blit фона).

## Профили (итерация 2)
- Вкладка Configs: список слева, профиль справа.
- «+ Новый» — пустой профиль, сразу можно ввести имя. Клик по имени — переименовать.
- «Включить» или двойной клик — переключиться (визуалы включаются/выключаются сразу).
- «+ Копия», «В файл» (→ config/umbra/exports), «Сбросить» (активный → всё по умолчанию), «Удалить» (два клика).
- Импорт: перетащи .json профиля в окно игры.
- Файлы: config/umbra.json (клиент), config/umbra/profiles/*.json (профили). Старый umbra.json сам переедет в профиль «Основной».

## Проверка с Sodium и Iris
`gradlew runClient` теперь запускает игру сразу с Sodium 0.8.7 и Iris 1.10.5.
Шейдеры: положи пак в `run/shaderpacks`, включи в Настройки → Видео → Пакеты шейдеров.
Выключить: `dev_sodium=false` в gradle.properties.

## Финальный jar
`gradlew build` → `build/libs/umbra-0.1.0.jar` → в `mods` вместе с Fabric API.

## Настройки игры (итерация 3)
- Главное меню → Настройки и пауза → Настройки открывают свой экран: Графика / Звук / Управление / Чат / Скин / Все настройки.
- Параметры в две колонки, внизу подсказка к наведённому. ПКМ по параметру — сброс к значению при открытии.
- «Все настройки» — ванильный экран (ресурспаки, язык, доступность и всё редкое).
- Масштаб интерфейса применяется при закрытии.
- Выключается: Umbra → Настройки → «Свои настройки игры».

## Визуалы, пачка 1 (итерация 4)
- HUD (вкладка HUD): кадры/с и пинг сверху справа, координаты, броня у хотбара.
- Hit Effects: частицы у цели при твоём ударе (6 видов, количество, разлёт).
- Hit Sounds: свой звук удара (5 звуков, громкость, тон). Слышишь только ты.
- Jump Circle: расходящийся круг на земле при прыжке.
- China Hat: конус над головой (от 3-го лица).
- Trails: лента-след за тобой, тает.
Всё рисуется только для тебя, с проверкой глубины (сквозь стены не видно), ничего не отправляется на сервер.
Код рендера в мире — только `render/WorldDraw.java`, HUD — `render/HudDraw.java`, удары — `render/CombatHooks.java`.

## Визуалы, пачка 2 (итерация 5)
- Block Outline: заливка + контур блока под прицелом, плавно переезжает.
- View Model: сдвиг X/Y/Z и размер рук (миксин `ItemInHandRendererMixin`, require=0 — если метод переименуют, просто не применится).
- Animations: скорость анимации взмаха (только картинка, кулдаун удара не меняется).
- Shulker Preview: содержимое шалкера над курсором в любом инвентаре, рамка в цвет шалкера.
- Item Cooldowns (HUD): перезарядка жемчуга/хоруса/щита полосками под прицелом.
- Crit Indicator (HUD): уголки у прицела, когда удар будет критом. Подсказка, не автоматика.

## Визуалы, пачка 3 (итерация 6)
- Crosshair (HUD): свой прицел — крест / точка / уголки, длина, зазор, толщина, цвет, обводка, полоса заряда удара.
- Zoom: приближение по удержанию C (меняется), плавная камера на время зума. Миксин `GameRendererMixin` (require=0).
- Ambience (World): своё время суток и без дождя — только у тебя.
- World Effects (World): снег, пепел, огоньки или пыльца вокруг.
- Target HUD (HUD): карточка цели после твоего удара — имя и здоровье.
- Keystrokes (HUD): WASD, пробел, ЛКМ/ПКМ с CPS.

## Оверлей Shift+Tab (итерация 7)
- В мире Shift+Tab (клавиша меняется: Umbra → Настройки → «Оверлей: Shift +»).
- Время в игре: всего, сегодня, сессия, 7 дней столбиками, топ серверов (config/umbra/stats.json).
- Скриншоты: 9 последних миниатюрами, клик — на весь экран, «Открыть папку».
- Быстро: переключение профилей, тумблеры модулей, ссылки «Браузер» (системный) и «Настройки Umbra».
- Пока закрыт — ноль работы; текстуры скриншотов освобождаются при закрытии.

## Аккаунты Microsoft (итерация 8)
Главное меню → АККАУНТЫ: список аккаунтов, «Войти через Microsoft», переключение в один клик, ✕ — удалить.
При запуске игры мод сам входит в последний выбранный аккаунт.
Файл: `config/umbra/accounts.json` (токены, не пароль — никому не отправляй).

### Один раз: свой Client ID в Azure
1. portal.azure.com → «Регистрация приложений» (App registrations) → «Новая регистрация».
2. Имя: Umbra. Типы учётных записей: **«Только личные учётные записи Майкрософт»**. URI перенаправления — пусто. «Зарегистрировать».
3. Скопируй **Идентификатор приложения (клиента)** — это Client ID.
4. Слева «Проверка подлинности» (Authentication) → внизу **«Разрешить потоки общедоступных клиентов» = Да** → Сохранить.
5. Впиши Client ID в `config/umbra/accounts.json`: `"client_id": "xxxxxxxx-xxxx-..."`.
6. Новые приложения Microsoft пускает к Minecraft только после заявки: https://aka.ms/mce-reviewappid
   (указываешь Client ID, обычно одобряют за несколько дней). До одобрения вход дойдёт до шага Minecraft и скажет об этом.

Ограничение: переключение без перезапуска не меняет подпись чата — на серверах со строгой проверкой подписи чата лучше перезапустить игру после смены аккаунта.

## Вкладки «Графики»
Основное / Детали / Качество / Эффекты / Оптимизация. В «Оптимизации» — главные ползунки FPS и кнопка «Все настройки Sodium».

## Waypoints (итерация 10)
- B — поставить точку там, где стоишь (клавиша меняется). «Убрать ближайшую» — своя клавиша.
- При смерти: координаты в чат (видишь только ты) и красная точка «Смерть».
- Лучи-маяки, по серверам и измерениям отдельно. Файл config/umbra/waypoints.json.

## Встроенный браузер (итерация 11)
- Shift+Tab → «Браузер»: Chromium прямо в игре (MCEF Modern). Назад/вперёд/обновить, адресная строка (адрес или поисковый запрос), закладки.
- Первый запуск браузера скачивает Chromium (~150 МБ) в фоне — на экране видно этап и проценты.
- Закрыл — браузер уничтожен, память освобождена. Без MCEF Modern кнопка открывает системный браузер.
- В dev-клиенте браузер включается `dev_mcef=true` в gradle.properties.

## Итерация 12
Визуалы: Target ESP (кольцо вокруг цели, без сквозь стены), Hitboxes (как F3+B, свои цвета), Trajectories (линия броска + точка падения).
Макросы (только по твоей клавише): Inventory Keys — Offhand Totem (R), Click Pearl, Hotbar Swap.
Chat Helpers: Auto Accept (/tpa от друзей), Auto Command (команды при входе), Kill Message, Auto Respawn, No Friend Damage.
Файлы в config/umbra: friends.txt, auto-commands.txt, kill-messages.txt — создаются сами при первом использовании.

## Музыка (итерация 13)
Виджет «Сейчас играет» — то, что звучит на компьютере: Spotify, Яндекс Музыка, VK, музыка в браузере.
Берётся из системной панели Windows (та же, что всплывает при нажатии клавиш громкости).
- Главное меню: справа снизу, кнопки ⏮ ⏯ ⏭ кликабельны.
- В игре: модуль **Music** (HUD) — угол, «прятать, когда ничего не играет», клавиши пауза/вперёд/назад.
- Работает **только при запуске через лаунчер Umbra** (лаунчер читает плеер и отдаёт игре по локальному порту с токеном). Из IDE/другого лаунчера виджет просто не появляется.

## Cosmetics (итерация 14)
Новая вкладка **Cosmetics**, модуль **Cape** — свой плащ, виден только тебе (F5, инвентарь).
- Рисунки: «Затмение», «Градиент», «Однотонный» (цвет настраивается) или «Свой файл».
- Свой файл: PNG 64×32 (развёртка как у обычных плащей) → `config/umbra/capes/cape.png`.
- В игре: Настройки → Настройки скина → «Плащ» должен быть включён.

## No Delay (итерация 15)
Вкладка **Player → No Delay**. Пока держишь ПКМ, блоки ставятся с задержкой 0–3 тика вместо ванильных 4.
«Для чего»: только блоки или всё. Начни с 1–2 — на 0 (20 блоков/сек) античит может ругаться.
